## MtkLogoBuilder
![Main Application Screen](https://i.ibb.co/Qv1JQxtw/Screenshot-From-2026-08-27-15-58-51.png)
MtkLogoBuilder is a program written in C++ as an alternative to the .NET Windows application LogoBuilder. It has the same features as the Windows version. There are still some quirks that need to be worked out, such as the file size of the produced logo.bin files.

### Usage
1) Click "Create project".
2) Select your stock logo.bin file
3) Edit the images as you wish
4) Click "Make"
5) Flash new logo.bin via xflash/SP Flash Tools
